# Code of Conduct

## Our Commitment

The Lost Code aims to maintain a professional, respectful, and constructive environment for everyone interacting with the project.

We believe meaningful collaboration starts with respect, responsibility, and open communication.

All participants are expected to treat one another with professionalism and courtesy.

## Expected Behavior

Everyone participating in the project is expected to:

- Be respectful and considerate.
- Communicate clearly and professionally.
- Provide constructive feedback.
- Respect different perspectives and experiences.
- Accept reasonable criticism gracefully.
- Focus discussions on improving the project.
- Respect the intellectual property and licensing terms of the project.
- Follow the repository's contribution and security policies.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Threatening, abusive, or offensive language.
- Trolling or deliberately disruptive behavior.
- Publishing another person's private information without permission.
- Spam, malicious links, or unrelated promotional content.
- Impersonation or misleading representation.
- Deliberate misuse of project resources.
- Unauthorized copying, redistribution, or commercial exploitation of proprietary project materials.

## Scope

This Code of Conduct applies to interactions related to The Lost Code, including:

- GitHub issues.
- Pull requests.
- Discussions.
- Project-related communication channels.
- Other spaces officially managed by the project.

## Reporting Unacceptable Behavior

If you experience or witness unacceptable behavior, please contact the project maintainer:

**GitHub:** https://github.com/Codewithpabitra

For security vulnerabilities, do not use public discussions or issues. Follow [SECURITY.md](SECURITY.md).

## Enforcement

The project maintainer is responsible for reviewing reported violations and determining appropriate action.

Depending on the severity and circumstances, actions may include:

1. A warning.
2. Removal of inappropriate content.
3. Temporary restrictions on participation.
4. Closure of discussions or issues.
5. Blocking or banning individuals from project-managed spaces.

The maintainer reserves the right to take appropriate action to protect the project and its community.
