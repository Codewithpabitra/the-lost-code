
The Memory Archive reveals a hidden passage leading toward the Syntax Wilds.

But the entrance is protected by a mechanical gate that has remained closed for centuries.

A display above the gate reads:

> ONLY THOSE WHO UNDERSTAND THE RULES MAY PASS.

Beneath the message, a numerical requirement appears:

**LEVEL 5**

You discover that the gate is controlled by a conditional system. It evaluates a condition and decides what action should happen.

In JavaScript, this is done using an `if` statement.

## Understanding if Statements

An `if` statement allows a program to execute code only when a condition is true.

### Example

```javascript
const level = 5;

if (level >= 5) {
  console.log("Unlocked");
}
```

The condition `level >= 5` checks whether the player's level is greater than or equal to 5.

If the condition is true, the code inside the curly braces executes.

### Comparison Operators

| Operator | Meaning |
|---|---|
| `===` | Strictly equal |
| `!==` | Not equal |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal |
| `<=` | Less than or equal |

## Your First Logic Test

The machine must check whether the current level is greater than or equal to 5.

If the condition is true, the gate will recognize the player as authorized and display the word `"Unlocked"`.

You are no longer simply displaying information.

You are teaching the machine how to make a decision.
