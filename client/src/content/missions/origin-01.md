You open your eyes in a place you cannot recognize. Towering ruins stretch across the horizon, ancient machines lie buried beneath the earth, and strange symbols glow faintly across the broken walls.

In front of you stands an enormous terminal. Its screen flickers for a moment before displaying a mysterious message:

> SYSTEM FAILURE — COMMUNICATION LOST

It appears that this machine once controlled something important, but its ability to communicate has been lost.

A faint voice suddenly echoes through the chamber.

"If you can hear me, the system is not completely lost. Give it a command. Make it speak again."

You discover that the terminal understands JavaScript. It cannot respond to complicated instructions yet, but it can display messages through a special command called `console.log()`.

This is where your journey begins.

Your first task is simple: restore the terminal's voice. Once it can display a message, you will have taken the first step toward bringing this forgotten world back to life.

## Understanding console.log()

JavaScript uses `console.log()` to display information in the output terminal.

### Example

```javascript
console.log("Hello, World!");
```

The text inside quotation marks is displayed in the terminal.

You can use this command to display messages, numbers, variables, and much more.

## Remember

- `console` is an object provided by JavaScript.
- `log()` is a method used to display information.
- Text values should be wrapped in quotation marks.
