# Contributing to The Lost Code

Thank you for your interest in **The Lost Code**.

The Lost Code is a proprietary project. We value feedback, suggestions, and responsible collaboration that can help improve the project.

However, all contributions are subject to the project's ownership, licensing, and approval policies.

## Before Contributing

Please read the repository's [LICENSE](LICENSE) before submitting any contribution.

**Submitting a contribution does not automatically grant permission to use, copy, modify, distribute, or commercially exploit the project.**

The project maintainer reserves the right to review, accept, reject, or request changes to any proposed contribution.

## Ways to Contribute

You can help improve The Lost Code by:

- Reporting reproducible bugs.
- Suggesting new features or improvements.
- Identifying usability and accessibility issues.
- Reporting security vulnerabilities privately.
- Providing technical feedback.
- Suggesting improvements to the learning experience.

## Reporting Bugs

Before reporting a bug:

1. Check whether the issue has already been reported.
2. Make sure you are using the latest available version.
3. Provide clear steps to reproduce the problem.
4. Include relevant error messages or screenshots.
5. Explain the expected and actual behavior.

Use the repository's Bug Report issue template when available.

## Suggesting Features

Feature suggestions are welcome.

Please include:

- A clear description of the proposed feature.
- The problem it aims to solve.
- Why it would improve the player experience.
- Any relevant examples or references.

Use the Feature Request issue template when available.

## Pull Requests

Pull requests are not automatically accepted.

Before submitting one:

1. Open an issue or contact the maintainer to discuss the proposed change.
2. Wait for approval before beginning substantial implementation work.
3. Keep changes focused and well documented.
4. Test your changes before submitting.
5. Clearly explain what was changed and why.

The maintainer may request additional information, modifications, or decline a pull request.

## Contribution Ownership and Permissions

Unless otherwise agreed in a separate written agreement:

- You retain ownership of original work you independently create.
- You must have the necessary rights to submit any material you contribute.
- You must not submit copyrighted or third-party material without appropriate permission.
- A submitted contribution does not grant you ownership of The Lost Code or its existing materials.
- The project maintainer does not receive an automatic right to redistribute your independently owned contribution merely because it was submitted.

Any contribution intended for inclusion in the proprietary project may require a separate written contribution agreement or license grant before acceptance and integration.

## Code Quality

For approved code contributions:

- Follow the existing project structure and conventions.
- Use clear and meaningful names.
- Avoid unnecessary dependencies.
- Preserve existing functionality unless the change requires otherwise.
- Keep frontend and backend responsibilities separated.
- Never commit secrets, credentials, tokens, or `.env` files.

## Security Issues

**Do not report security vulnerabilities through public issues or pull requests.**

Follow the instructions in [SECURITY.md](SECURITY.md) instead.

For project-related questions, see [SUPPORT.md](SUPPORT.md).
