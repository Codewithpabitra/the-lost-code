# Support

## The Lost Code

Need help with **The Lost Code**?

This document explains where to ask questions, report problems, and find project-related information.

## Before Requesting Support

Before opening a support request:

1. Read the [README.md](README.md).
2. Check the installation and setup instructions.
3. Review existing GitHub issues for similar questions.
4. Make sure you are using the latest available version.
5. Check whether the problem is related to your local environment or configuration.

## Getting Help

For project-related questions or assistance, use the following channels:

### GitHub Issues

https://github.com/Codewithpabitra/the-lost-code/issues

Use GitHub Issues for:

- Installation and configuration questions.
- Reproducible bugs.
- Unexpected application behavior.
- Feature suggestions.
- General technical feedback.

Please provide enough context for the maintainer to understand your problem.

### GitHub Profile

Maintainer: **Pabitra Maity**

https://github.com/Codewithpabitra

You can use the profile to find the maintainer's available contact and professional links.

## Reporting a Bug

When reporting a bug, include:

- A short and descriptive title.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Relevant error messages.
- Your operating system and browser, if applicable.
- Screenshots or logs, when useful.

Use the Bug Report template when available.

## Requesting a Feature

Feature requests should explain:

- What you want to improve.
- Why the improvement is useful.
- How it could benefit the player experience.
- Any examples or references that help explain the idea.

Use the Feature Request template when available.

## Security Support

**Never report security vulnerabilities through public GitHub issues.**

For security-related concerns, follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## What Is Not Covered

Support does not guarantee:

- Individual development or implementation services.
- Immediate responses or resolution times.
- Custom feature development.
- Compatibility with every operating system or environment.
- Assistance with unauthorized modifications or redistribution.

## Response Expectations

The project is maintained independently.

Responses depend on availability, issue complexity, and project development priorities. There is no guaranteed response or resolution timeframe.
